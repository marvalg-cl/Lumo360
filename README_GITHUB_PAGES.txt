LUMO360 VISION 6 · GitHub Pages

1. Sube el CONTENIDO de esta carpeta directamente a la raíz del repositorio.
2. Debe existir index.html en la raíz.
3. GitHub → Settings → Pages → Deploy from a branch → main → /(root).
4. Espera el despliegue y abre https://marvalg-cl.github.io/Lumo360/
5. Si el teléfono mantiene una versión antigua, cierra la PWA/navegador y abre una pestaña privada una vez.

Esta versión conserva el núcleo funcional de LUMO360 y reconstruye la capa de interfaz como un sistema visual único: navegación por espacios, centro de mando, fichas, documentos, tarjetas operativas, responsive móvil y PWA.
