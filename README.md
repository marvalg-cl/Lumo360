# Lumo360 · LUMOBRAL

Versión visual basada directamente en el PDF `cotz1.pdf` entregado por LUMOBRAL.

El motor de PDF de cotizaciones reproduce y mejora la estructura del documento de referencia: logotipo LUMOBRAL, encabezado institucional, línea naranja fina, tarjetas de cliente y condiciones, tabla oscura, bloque de totales, términos y condiciones, firmas y pie institucional.

El naranja queda limitado a los acentos del documento. La información se genera dinámicamente desde los datos de Lumo360.

Los iconos se actualizaron tomando como referencia el logotipo del PDF entregado.

Todos los archivos están en la raíz de una única carpeta para GitHub.
