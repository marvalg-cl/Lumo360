# LUMO360 CRM/ERP · Lumobral · FINAL

Versión final preparada para GitHub Pages.

## Incluye
- IndexedDB como almacenamiento principal, con respaldo local cuando el navegador no lo permite.
- Modo claro y modo oscuro, persistentes.
- Sistema de iconos SVG de referencia Lumobral, con colores semánticos.
- Identidad gris grafito + naranja Lumobral.
- Responsive móvil/PC con navegación inferior en móvil.
- Manifest PWA y Service Worker.
- PDF vectorial con texto (jsPDF), no PDF convertido a imagen.
- Exportación/importación y módulos CRM/ERP existentes.

## Publicación
Sube el contenido de esta carpeta a la raíz de un repositorio de GitHub y activa GitHub Pages.
